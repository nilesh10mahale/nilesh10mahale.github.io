ECHO

Drag-and-drop portfolio builder for creatives, from wireframe to live site in minutes.

ROLESolo developer
TIMELINE10 weeks
STACKReact / Node.js / Postgres

The Problem

Creatives who aren't developers still need a fast, good-looking portfolio site — but most site builders are either too generic (templated, stiff) or too complex (full design tools with a learning curve).

The Approach

  • Built a drag-and-drop canvas with a constrained set of pre-designed blocks, so every layout stays visually consistent no matter how it's arranged.
  • Node.js/Postgres backend handles per-user sites, versioned drafts, and one-click publish to a live subdomain.
  • Kept the editor state fully undoable and autosaved, so nothing is ever lost mid-edit.

Key Decisions

The core design bet was constraint over flexibility — fewer block types than a typical page builder, each one pre-styled, so users can't easily make something that looks broken. That trade-off is what makes 'minutes to live site' realistic.
