PULSE

Real-time analytics dashboard processing 2M+ events per day with sub-100ms updates.

ROLESolo developer
TIMELINE6 weeks
STACKReact / WebSockets / D3.js

The Problem

Teams monitoring high-traffic products needed to see what was happening right now, not five minutes ago after a page refresh. Existing dashboards polled on an interval, which meant stale numbers during the moments that mattered most — traffic spikes, error surges, campaign launches.

The Approach

  • Designed a WebSocket-based event pipeline so the UI updates the instant new data arrives, instead of polling on a timer.
  • Built custom D3.js visualizations tuned for high-frequency updates without janky re-renders.
  • Added client-side batching and throttling so a 2M-events-a-day firehose doesn't overwhelm the browser.

Key Decisions

The trickiest part was keeping the UI smooth under load. Naive re-rendering on every event would have killed frame rate, so updates are batched into 100ms windows and diffed before touching the DOM. That's what gets the sub-100ms perceived latency without sacrificing render performance.
